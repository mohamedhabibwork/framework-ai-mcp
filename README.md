# @framework/ai-mcp

MCP server bridging the framework CLI and documentation for AI coding agents.

> **Read-only subtree split** — This package is developed inside the main [**mohamedhabibwork/framework**](https://github.com/mohamedhabibwork/framework/tree/main/packages/ai-mcp) monorepo and automatically synced to [`mohamedhabibwork/framework-ai-mcp`](https://github.com/mohamedhabibwork/framework-ai-mcp). Please open issues and pull requests in the main framework repository.

## Installation

### Inside a Standalone App (via GitHub)

```json
{
  "dependencies": {
    "@framework/ai-mcp": "github:mohamedhabibwork/framework-ai-mcp"
  }
}
```

```sh
bun install
```

### Creating a New Application

Use the starter application template repository to bootstrap a full application with all framework packages pre-wired:

```sh
gh repo create my-api --template mohamedhabibwork/framework-app --clone
cd my-api
bun install
```
